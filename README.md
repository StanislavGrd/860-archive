# 860 Archive – Streetwear Shop

Eine Shop-Website für eine fiktive Streetwear-Marke mit Premium-Shirts, entstanden als Projekt im Studium (Media Engineering, TH Nürnberg, SoSe 2026).

## Features

- Produktübersicht mit Shirt-Designs
- Warenkorb
- Live-Uhr im Header
- „Crew Feed“: Besucher können Kommentare posten

## Technologien

HTML · CSS · JavaScript
